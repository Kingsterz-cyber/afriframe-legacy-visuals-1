Afriframe Booking Platform

A booking management web app for Afriframe Pictures built with React, TypeScript, Vite, Firebase, and EmailJS. It allows clients to request bookings and lets admins manage, confirm, or cancel them. Confirmed bookings automatically send emails to clients.

🚀 Features
For Clients

Submit booking requests with details: name, email, phone, date, time, service, and optional message.

Receive automatic email notifications on booking confirmation or updates.

For Admins

View all bookings in a dashboard.

Filter bookings by status: Pending, Confirmed, Cancelled.

Confirm or cancel bookings.

Optional admin message can be sent to clients when updating bookings.

Email notifications sent automatically using EmailJS.

🛠 Tech Stack

Frontend: React, TypeScript, Vite

UI Components: ShadCN/UI, Tailwind CSS, Lucide Icons

Backend / Database: Firebase Firestore

Email Service: EmailJS

Notifications: Sonner toast notifications
